# Instructions du projet

- Poursuivre l'objectif défini dans `docs/ROADMAP.md` jusqu'à une livraison vérifiable. Ne pas présenter une simulation comme une validation dans Logic Pro.
- Pour les recherches simples et indépendantes, orchestrer des sous-agents **Luna, effort élevé**, par vagues si la limite de concurrence empêche d'en exécuter six simultanément. Garder la synthèse, les choix d'architecture et les modifications coordonnées dans la tâche principale.
- Le projet de référence est une source à évaluer, pas une cible à copier en bloc. Lire `docs/REFERENCE.md` avant d'en reprendre du code et vérifier les nouvelles issues et pull requests pertinentes.
- Le README et les messages d'installation s'adressent à des musiciens. Préférer un paquet prêt à lancer et des instructions courtes, avec des termes compréhensibles.
- Distinguer les versions de Logic, la version du serveur, le SDK MCP et la révision du protocole MCP.
- Tout comportement spécifique à Logic 11.1 ou 11.2 doit avoir une preuve ou être explicitement marqué non vérifié.
